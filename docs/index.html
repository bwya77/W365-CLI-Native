W365 CLI
Built for fleet admins

A faster way to work through everyday Cloud PC tasks.

If you manage a fleet of Cloud PCs, you know the routine: restart one, resize another, check on a snapshot, review a provisioning policy. W365 CLI brings those everyday actions into a single, fast, keyboard-driven view so you can move through them quickly.

Speed

Act on your fleet in seconds

Filter, sort, and run actions on Cloud PCs without repeating the same navigation steps for every device.

Focus

Stay in the terminal

Keep your fleet, your scripts, and your workflow in one place instead of switching between windows.

Scale

Built for bigger fleets

Instant filtering and a command palette make it easy to work across dozens or hundreds of Cloud PCs at once.

Why we built it
We manage Windows 365 fleets too, and wanted a keyboard-first way to move through the same tasks we do every day: browsing, filtering, and acting on Cloud PCs.
  • Open source on GitHub, so you can inspect every line before you trust it with your tenant
  • Windows binaries and installers signed with Azure Trusted Signing
  • macOS builds signed with an Apple Developer ID certificate
  • Every release ships with SHA256 checksums for Windows and macOS assets
  • Built on Microsoft Graph delegated permissions, so no standing admin credentials are stored
  • Checks GitHub Releases on startup and can install updates for you automatically

Get started

Three steps from download to managing your fleet.

One command gets you a working install on any platform — no manual setup.

1

Install

On Windows, run the one-liner or download the installer — it adds w365cli to your PATH automatically, no admin rights needed. On macOS, paste the install command into Terminal.

2

Sign in once

Run w365cli and connect with your Microsoft Graph account. MSAL caches your session so you won't need to sign in again on every launch.

3

Manage your fleet

Browse, filter, restart, resize, snapshot, and reprovision Cloud PCs, all from the keyboard.
